      FUUUCK! I got it!

      It was right in front of me. What the answer was for me was specifically Task_Plane_Missions flags.

      Check this out:

      MISSION_NONE = 0, // 0 MISSION_CRUISE, // 1 MISSION_RAM, // 2 MISSION_BLOCK, // 3 MISSION_GOTO, // 4 MISSION_STOP, // 5 MISSION_ATTACK, // 6 MISSION_FOLLOW, // 7 MISSION_FLEE, // 8 MISSION_CIRCLE, // 9 MISSION_ESCORT_LEFT, // 10 MISSION_ESCORT_RIGHT, // 11 MISSION_ESCORT_REAR, // 12 MISSION_ESCORT_FRONT, // 13 MISSION_GOTO_RACING, // 14 MISSION_FOLLOW_RECORDING, // 15 MISSION_POLICE_BEHAVIOUR, // 16 MISSION_PARK_PERPENDICULAR, // 17 MISSION_PARK_PARALLEL, // 18 MISSION_LAND, // 19 MISSION_LAND_AND_WAIT, // 20 MISSION_CRASH, // 21 MISSION_PULL_OVER, // 22 MISSION_PROTECT // 23

      Using this with conjunction with the cruise speed parameters means that the plane will start to slow down without cutting the engine, and the plane follows regular physics without both sinking to the ground like a rock (taskgotocoordlongrange) or ignoring flight characteristics completely (taskplanemission with missionflag 4).

      I don't think it's controllable, however, if I can set up lineups, I think we'll have something here!
