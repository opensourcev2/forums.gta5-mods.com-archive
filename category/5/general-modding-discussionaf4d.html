      How to edit the game colors and clouds?
      • bandaidu

      2
      2
      Posts
      158
      Views

      M

      @bandaidu You can download it and get the v_cloudhats.rpf (You need to use weather.xml as well or at least copy paste cloud names that appear in each weather).

      Colors can be edited in timecycle files, though there are simply too many stuff to say which value will give you what you actually want. But I can suggest you to start with these (you probably won't need the rest);

      light_dir_col_ light_directional_amb_col_ light_natural_amb_down_col_ light_natural_amb_up_col_ light_artificial_int_down_col_ <!-- Only for interiors --> light_artificial_int_up_col_ <!-Only for interiors --> light_aritificial_ext_down_col_ <!-Only for exteriors --> light_artificial_ext_up_col_ <!-Only for exteriors -->

      Each of these values have R, G, B letters at the end which represents to Red, Green, Blue colors (in case didn't know).

      You might as well just copy paste these values from NVR.

      There are some side values like intensity, intensity_multiplier which might be necessary to use but can come with a tiny performance impact. Although you probably won't even notice such a small fps loss.
