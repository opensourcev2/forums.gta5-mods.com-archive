      @SkylineGTRFreak said in [Vehicle][Released] Predator Drone with Hell fire Missiles:

      @FoxtrotDelta well, for one make sure you have a UV map on the second UV channel.

      To easily do that, go to Surface->Mapping->Edit UV. Click on each object and use following settings:

      Edit UV Channel map #1

      Generate New

      Copy from channel #1

      Everything else not selected. ->OK

      Once done, just switch one window to UV mapper view and back to normal window. (Otherwise ZM3 might get laggy)

      Now toggle on the "Burn" button on the "Structure" tab. Your model should be all black now.

      Go to Surface->Paint. The "Paint..." Tab will have an arrow symbol to the right. Click on it (it should have RGB selected. You want to select B.)

      Now The left symbol should be "Paint vertices to select color". Again click on the right arrow on the top right. Color: Black.

      Go to vertices mod and select all of your model. Press "fill selected" on the paint vertices options window. Your model should look normal now.

      Now select color: white. You now have the paint tool and can draw anywhere on the model, so to say. Anywhere you draw, it should become black. Those parts will get the burn effect later in game.

      Hope it helped
