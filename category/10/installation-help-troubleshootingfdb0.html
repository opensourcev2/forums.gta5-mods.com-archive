      @spookyglockz Bruh, no idea what the prob is. Going to need way more info on what's happening to figure out what's up. Off the top, check the following to get any clues;

      Check 'Event Viewer' in Windows immediately after the game crashes. Go into 'windowlogs', then 'applications'. There should be an 'error warning' with a 'red X' and an 'error message' listed underneath. Read both. Most likely it will say there's a problem with GTAV or a .NET Framework issue. That means there's a conflict with the game and one or more mods. The .NET thing means a conflict with .NET Framework based mods. Either or both, you'll have to dig through everything to find the problem.

      Also, do not restart the game after a crash. Go into the GTAV main folder and scroll down 'til you find the 'ScripthookV log file'. Scroll down to the bottom entries of the file. If there was a scripthook error, the last entry BEFORE the list of mods being 'disabled' is usually what caused the problem.

      Same as #2 goes for the DotNet logfile. The last entry is where the game stopped loading. Start looking for issues with the last mod listed.

      (Optional) If you have Menyoo, lately that causes a lot of crashes. Check the Menyoo logfile for the same things as #2 and 3.

      @Lovis_Avgvstvs Sorry my message lacked some info which led to misunderstandings.

      By heavily/lightly modded I meant graphic mods and other type of stuff that doesn't have a direct involvement with the traffic. This also includes replace/addon cars. So in a more easy explanation, game using 2 GB VRAM and 12 GB VRAM won't effect the traffic variety.

      Obviously the variety can be increased by editing settings.xml and modifying vehicles.meta . Lower the MaxNum number for a car, and if the value is 3, game won't spawn 4 of that particular car. If you make it 1, then you won't see 2 of that car.

      So you might obviously think, "Then can't I just make MaxNum value = 1 for every cars?". If you do that, game won't spawn any car. You might see a single car here and there but they are not the ambient traffics, they will be the scenario spawned cars.
      Unlike Ambient Traffic controlled by an automated weak AI, Scenario Spawned vehicles are controlled by predetermined settings; where they will spawn, which vehicle will spawn and which route they will take are predetermined inside scenario ymt files. The dune buggy you see near Sandy Shore airfield's dirt road, or a Kalahari car spawning at Chumash FWY are scenario vehicles. Same as the Frogger helicopter flying above the beach alongside the shoreline.

      I saw identical cars in both GTA SA and 4. So, that's the way they designed the game at engine level which you won't be able to tamper.
