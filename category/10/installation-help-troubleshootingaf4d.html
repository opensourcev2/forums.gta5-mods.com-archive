      Are you using an outdated version of the game?
      The Native your game is referring to toggles the Cayo Perico map on and off, introduced in b2189. If you're using a version of the game older than that, then a script of some description is calling a native that doesn't exist in your game.

      HUD::SET_USE_ISLAND_MAP
      void SET_USE_ISLAND_MAP(BOOL toggle) // 0x5E1460624D194A38 b2189
      Toggles the Cayo Perico map.
      Old name: _SET_TOGGLE_MINIMAP_HEIST_ISLAND
