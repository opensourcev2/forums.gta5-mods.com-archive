      @james34 said in Script Hook V .NET:

      @MissySnowie said in Script Hook V .NET:

      @james34 The scripthook net is needed if you install .dll scripts. They go to Grant Theft Auto V\scripts folder.

      For .asi scripts only, you only need the normal scripthook itself

      Awesome. thank you.

      Just to add to what @MissySnowie wrote, it's recommended to install the dot net files if you intend to install script mods or write some yourself. The reason your trainer worked is because it is loaded by a file called the asi loader. As Snowie wrote, trainers and asi mods (renamed but more complex dlls) require ScripthookV as it allows the Trainer to communicate with the RAGE engine. Note: The asi loader is the file called dinput8.dll and it is bundled with OpenIV as well.
