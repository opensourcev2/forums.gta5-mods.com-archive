      I am currently developing a few mods that require me to write libraries to reuse code. For example an OBD inspired mod that allows me to grab any car data and display it on my phone, a website or whatever you can think of. This way i can create detailed graphs for tuning/dyno'ing or a custom real-life spedometer etc.

      Currently i have the following implemented

      • Websocket server lib
        This is for sending and recieving any data. Since it is a server, there is no hard limit on devices that can recieve data. Port can be changed at will, authentication is implemented too (allthough not nessesary in a local network).

      • GlobalEvents lib
        Universal library to register, recieve and trigger events across entire mods, threads, and/or classes.

      • Decors lib
        Allows to save custom data (Bool, Int, Float) on Entities which can be accessed by any other script/mod. SHVDN only has the natives and they also dont work correctly by default. This lib adds the functions and makes nessesary memory edits to the game to unlock the locked decors.

      One of the reasons is simply that there seems to be no good libraries out there and the few "helper" mods are just utter garbage.

      What can you do with this? (very simple example)
      A lot with basically no code at all. For example, the Decors allow me to store if and which neon lights have been purchased directly onto a car (which then allows me to allow a neon-toggle only if the car has actually purchased them):

      if (Decors.DecorExistOn(vehicle, "NEON_PURCHASED")) { return; };
// ...
Decors.DecorSetBool(vehicle, "NEON_PURCHASED", true);

      An eventhandler (global events) looks like this:

      private lib.globalevents.GlobalEvents Events = lib.globalevents.GlobalEvents.Instance;
public ClassConstructor()
{
    Events.Subscribe("ToggleNeon", OnToggleNeon);
}
private void OnToggleNeon(params object[] args)
{
    neon();
}
